### Ex 1-9
 - 복사된 참조 변수에 새로운 객체 자체를 할당했을 때 원본 변수와의 관계 변화를 비교
 - 원시 값을 복사한 변수 b의 값을 변경하는 것은 원본 a에 영향을 주지 않음
 - 객체를 복사했던 변수 obj2에 완전히 새로운 객체를 할당하면, obj2는 이 새 객체를 참조
 - 원본 변수 obj1은 여전히 기존 객체를 가리키므로, obj1과 obj2는 서로 다른 객체를 참조하게 되어 연결이 끊어짐

### Ex 1-10
 - 객체의 가변성으로 인해 함수가 전달받은 원본 객체를 의도치 않게 변경하는 문제
 - 함수 내에서 인자로 받은 객체의 참조를 복사(newUser = user)하여 사용하면, 내부 변수와 원본 변수가 같은 객체를 가리킴
 - 이 상태에서 내부 변수로 객체의 프로퍼티를 수정하면 원본 객체 자체가 변경되는 부수 효과가 발생
 - 결과적으로 함수 호출 후 원본 변수 user와 함수가 반환한 변수 user2는 모두 변경된 동일 객체를 참조

### Ex 1-11
 - 예제 1-10에서 발생한 원본 객체 훼손 문제를 새로운 객체를 생성하여 반환하는 방식으로 해결
 - 수정된 changeName 함수는 전달받은 객체를 직접 수정하지 않고, 변경된 name과 기존 gender 값을 포함하는 완전히 새로운 객체를 만들어 반환
 - 이 결과 원본 user 객체는 'Jaenam'이라는 이름을 그대로 유지하며 변경되지 않음
 - 반환값을 받은 user2는 원본과 다른 새로운 객체를 참조하게 되어, 원본 객체를 보호하고 의도치 않은 변경을 막음

### Ex 1-12
 - 전달받은 객체의 프로퍼티들을 복사하여 새로운 객체를 만들어 반환하는 copyObject 함수를 정의
 - 함수는 for...in 구문을 이용해 원본 객체 target의 모든 프로퍼티를 확인하고, 그 이름과 값을 그대로 새 객체 result에 복제

### Ex 1-13
 - 예제 1-12에서 만든 copyObject 얕은 복사 함수를 사용하여 user 객체를 복사
 - copyObject는 새로운 객체를 반환하므로 user2는 원본 user와 다른 객체를 참조
 - 복사본인 user2의 name 프로퍼티를 'Jung'으로 변경해도 원본 user 객체의 name 프로퍼티 'Jaenam'는 영향을 받지 않음

### Ex 1-14
 - 내부에 또 다른 객체 urls를 가진 객체 user를 얕은 복사 함수로 복사할 때의 동작을 보여주는 예제
 - 얕은 복사로 생성된 user2는 user와 별개의 객체이지만, 한 단계 안의 urls 프로퍼티는 원본 user의 urls와 동일한 객체를 참조
 - 얕은 복사가 중첩된 객체까지 새로 복사하지 않고 참조만 복사하기 때문에 발생하는 현상

### Ex 1-15
 - 얕은 복사 함수 copyObject를 활용하여 중첩된 객체까지 복사하는 수동적인 방식의 깊은 복사 방법
 - user 객체 전체를 얕게 복사하여 user2를 만들고, user2의 urls 프로퍼티에 원본 user.urls 객체를 다시 copyObject 함수로 복사하여 할당
 - user2.urls는 user.urls와는 별개의 객체를 참조하게 되어, 한쪽의 urls 내부 값을 변경해도 다른 쪽에 영향을 주지 않음

### Ex 1-16
 - 객체 내부의 모든 중첩된 객체까지 포함하여 깊은 복사를 수행하는 범용 함수 copyObjectDeep을 정의
 - 함수는 재귀(recursion) 방식을 사용하여, 복사 대상의 프로퍼티 값이 객체일 경우 해당 값에 대해 다시 copyObjectDeep 함수를 호출
 - 원본 객체와 동일한 구조를 가지면서 내부의 모든 값이 복사된, 참조를 공유하지 않는 완전히 독립적인 새로운 객체를 생성할 수 있음

### Ex 1-17
 - 예제 1-16에서 정의한 깊은 복사 함수 copyObjectDeep을 실제 중첩된 객체에 적용
 - obj에서 변경한 내용은 obj2에 영향을 주지 않고, obj2에서 변경한 내용도 obj에 영향을 주지 않음

### Ex 1-18
 - JSON.stringify로 객체를 문자열로 만들고 JSON.parse로 다시 객체화하여 간편하게 깊은 복사를 수행하는 함수
 - 이 기법은 객체의 중첩 구조를 포함하여 모든 값을 복사하므로, 원본(obj)과 복사본(obj2) 간의 참조가 완전히 끊어져 서로 영향을 주지 않음
